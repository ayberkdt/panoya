# 17 — Attachments, import/export and independent backup

## Attachments
Local Blob store keyed by SHA-256 and workspace (no cross-user dedup visibility). Metadata canonical attachment ID, safe display filename, MIME, bytes, hash, upload status. Validate size/type; default per file 20 MB configurable, total budget show estimate. Detect obvious MIME mismatch; SVG/HTML not rendered as trusted active DOM; downloads sandbox or safe viewer. Object URLs revoke. Images alt text/caption, PDF inline only if safe browser viewer supports, fallback open/download. Binary blobs not indexed. In cloud mode upload to private bucket, checksum verification where feasible, retry idempotent object key, publish reference only with availability status; local pending blob can remain while metadata syncs. Garbage collect only unreferenced after explicit cleanup and retention; avoid deleting shared blob still referenced.

## Backup format
ZIP manifest JSON: formatVersion, createdAt, appVersion, workspaceId, schemaVersion, entity counts, checksums, completeness, required feature versions. `entities/*.json` stable canonical schema, `blobs/<sha256>` binary, optional `readable/*.md`. Include folders, pages, blocks, datasets, tags, settings, FX snapshots, conflicts/recovery drafts if selected. Exclude auth tokens, sync secrets, disposable caches; remote IDs/versions reset on import to new local workspace. Export snapshot transaction for metadata, immutable blob references; if missing blob explicitly mark incomplete, never claim full. No automatic upload. Optional encrypted backup P2 only with reviewed format and key recovery warnings; default ZIP not encrypted, warn private data.

## Restore
Inspect ZIP manifest, enforce size/count/compression limits and safe paths (no traversal, absolute paths, symlinks), verify checksums and schemas, show preview of counts/unknown blocks/missing refs. Default restore to new workspace preserving internal IDs if no namespace collision, otherwise generate mapping atomically. Import into existing workspace explicit merge with remap; never overwrite without confirmation. Staging DB or transaction ensures failure leaves original intact. Unknown future block payload preserved read-only; incompatible major schema refuse with explanation. Backup roundtrip checks all records and hashes. History optional separate; clear sync state on restore unless explicit supported reattach. No ZIP bomb or path traversal.

## Human-readable export
Page/notebook/workspace Markdown with relative links and attachment paths, JSON lossless, sanitized HTML, print/PDF via browser print stylesheet with page breaks, accessible tables and chart snapshots when available. PDF and Markdown intentionally lossy for interactive blocks; include static value, units, source date and formula source where meaningful; never say PDF restores functionality. CSV data export per 10. Import Markdown plain with links and code, preview unsupported extensions; HTML sanitized; no network fetch. Test missing file, malicious zip, malformed JSON, Unicode filenames, duplicate import, same IDs and checksum mismatch; compare exact canonical semantic equality after full roundtrip.
