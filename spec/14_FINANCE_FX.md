# 14 — Personal finance and foreign exchange

## Scope and model
Manual personal balances and optional transactions, not banking/accounting. Account fields id, label, type cash/bank/savings/other/liability, currency ISO 4217, balance canonical decimal string, asOf date, notes. Balance mode uses recorded snapshots; optional ledger mode derives from opening balance + transactions, never double counts both. Transfers in ledger create linked debit/credit entries atomically; cross-currency transfer stores actual source/destination amounts and fees, no implied rate. Portfolio has base currency, account selection, rate mode, snapshot references. Show assets, liabilities and net separately; liabilities stored nonnegative magnitude with type sign. No card/account numbers required. No live banking, trading, tax or investment advice.

## Precision
Use Decimal.js or equivalent, canonical decimal strings, no JS Number for monetary arithmetic. Define currency minor units via maintained ISO table (JPY 0, EUR/TRY 2 examples), configurable precision for rates. Retain intermediate precision (e.g. 34 significant digits, verify library semantics), round HALF_EVEN at presentation/report boundary, store original entered amounts. Sum unrounded conversions then round total; per-row rounded amounts may differ by a cent, disclose. User locale formatting separated from parsing; negative values explicit; reject nonfinite/invalid amount, unsupported currency not zero. Chart numbers converted only after exact totals; accessible table exact.

## FX provider
RateSnapshot `{id,provider,base:'EUR',effectiveDate,retrievedAt,rates:{EUR:'1',TRY:'50',USD:'1.1'},kind:'reference'|'manual'}`. Reference rates e.g. ECB daily reference series, not real-time executable prices; note publication calendar, weekend/holiday, missing currencies. Provider adapter returns validated positive finite decimal rates with same base/date; use backend proxy only if needed for CORS or provider requirements, no balance/notes transmitted. Fetch public rates once per configured refresh, cache by provider/date, request deduplication, bounded retry, cancellation, stale indication based on effective date and provider schedule. Manual override records date/source, not silently replacing official value. No free API quota guarantee; local manual mode always functional.

Conversion: with r_X = units X per 1 EUR, `amount_Y = amount_X * r_Y / r_X`. EUR rate=1. If X=Y return unchanged, no fetch needed. Cross-rate requires both from same snapshot; if missing report incomplete totals and list accounts. Never mix rates with different dates silently. Offline use last stored snapshot with date/stale badge or manual rate; never present stale as live. For historical portfolio snapshots store rate snapshot ID and original balances, so old values don't change when new rates fetched; optional mark-to-market history separate. Display converted total, per-currency subtotal, asset distribution, balance timeline; actual historical snapshots, no invented interpolated balances.

## UI flow
Finance notebook → Portfolio block → Add account rows; label/currency/amount/type/date; base EUR/TRY/USD selector; rate mode latest reference / fixed snapshot / manual; rate source/date visible; total + per-currency and asset-only donut; edit amount updates totals/percentage. Optional expense tracking category chart P1, budgets and transfers P1; clearly distinguish balance vs income/expense. Export local CSV/JSON; mask amounts toggle for screenshots P1.
